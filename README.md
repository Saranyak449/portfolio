# Saranya K - Portfolio

My personal developer portfolio built with React and Vite.

Live site: https://portfolio-saranya-01d3.vercel.app

## Run locally

```bash
git clone https://github.com/Saranyak449/portfolio.git
cd portfolio
npm install
npm run dev
```

Open http://localhost:5173 in your browser.
